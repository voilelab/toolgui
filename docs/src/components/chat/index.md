# Chat Components

The chat components build a conversational interface, such as a chat with a
model.

```go
import "github.com/voilelab/toolgui/toolgui/tgcomp"
```

These components are shown on the `chat` page of the demo app: [run it in
your browser](../../demo/#/chat), or `task run_demo` and open
http://localhost:3000/chat.
